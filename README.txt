Отчёт гофролинии для Android (PWA)

Эта папка устанавливается как приложение через Chrome, но её нужно выложить в интернет (нужен адрес https://).
1. Откройте https://app.netlify.com/drop и перетащите распакованную папку (или загрузите её на GitHub Pages).
2. Откройте полученную ссылку на телефоне в Chrome.
3. Меню Chrome (три точки) -> "Установить приложение". Иконка появится на экране, приложение работает без интернета.

Нужен именно файл .apk? Откройте https://www.pwabuilder.com, вставьте ссылку из шага 2 и выберите Android: сервис соберёт APK.
Данные хранятся в самом приложении на телефоне.

Синхронизация отчётов между устройствами (один раз, около 5 минут)
1. Откройте https://console.firebase.google.com, войдите аккаунтом Google и создайте проект (Google Analytics можно отключить).
2. Слева: Build -> Realtime Database -> Create Database (любой регион, режим "locked").
3. Вкладка Rules: вставьте это и нажмите Publish:
   {"rules":{"$code":{".read":true,".write":true}}}
4. Скопируйте адрес базы с вкладки Data (вида https://имя-default-rtdb.firebaseio.com).
5. В приложении: История -> Синхронизация -> Подключить, вставьте адрес. Приложение создаст секретный код.
6. На втором устройстве: История -> Синхронизация -> Подключить, вставьте "Ключ подключения" с первого устройства.
Данные доступны только по секретному коду из ключа. Не публикуйте ключ.
