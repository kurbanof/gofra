Отчёт гофролинии для Android (PWA)

Эта папка устанавливается как приложение через Chrome, но её нужно выложить в интернет (нужен адрес https://).
1. Откройте https://app.netlify.com/drop и перетащите распакованную папку (или загрузите её на GitHub Pages).
2. Откройте полученную ссылку на телефоне в Chrome.
3. Меню Chrome (три точки) -> "Установить приложение". Иконка появится на экране. Первый запуск сделайте с интернетом (приложение один раз сохраняет библиотеку Vue и шрифт), дальше оно работает без интернета.

Нужен именно файл .apk? Откройте https://www.pwabuilder.com, вставьте ссылку из шага 2 и выберите Android: сервис соберёт APK.
Данные хранятся в самом приложении на телефоне.

Синхронизация отчётов между устройствами (один раз, около 5 минут)
1. Откройте https://console.firebase.google.com, войдите аккаунтом Google и создайте проект (Google Analytics можно отключить).
2. Слева: Build -> Realtime Database -> Create Database (любой регион, режим "locked").
3. Вкладка Rules: вставьте это и нажмите Publish:
   {"rules":{"$code":{".read":true,".write":true}}}
4. Скопируйте адрес базы с вкладки Data (вида https://имя-default-rtdb.firebaseio.com).
5. В приложении: Ещё -> Синхронизация -> Подключить, вставьте адрес. Приложение создаст секретный код.
6. На втором устройстве: Ещё -> Синхронизация -> Подключить, вставьте "Ключ подключения" с первого устройства.
Данные доступны только по секретному коду из ключа. Не публикуйте ключ.

Бланк «Сменный отчёт» (печать, PDF, почта)
Откройте раздел «Отчёт» и проведите пальцем влево: откроется «Бланк» (вправо: назад к списку заказов). Данные берутся из заказов: номер, техкарта, размеры, план, факт, брак и поле «Сырьё». В таблице «Сырьё» у каждого заказа не меньше 3 строк (пустые остаются для записи от руки), больше — если заполнено больше слоёв. Внизу бланка в «Итого за смену»: брак заготовок (кг), отходы заготовок (брак заготовок + отходы смены, которые вводятся в конце смены) и рулонные отходы. Рулонные отходы вводятся на бланке и ни с чем не суммируются.
План на месяц считается по сменам: смены это все дни с понедельника по пятницу.
Кнопки: «Печать» (лист А4 альбомный), «PDF» (файл сохраняется на телефон), «На почту» (окно «Поделиться» с PDF: выберите Gmail или другую почту).
Тема оформления: Ещё -> Настройки -> Тема.

Дата и жесты
При запуске открывается сегодняшняя дата. Если вы смотрите другой день, под заголовком появляется кнопка «Сегодня» для быстрого возврата. Нажатие на дату сразу открывает календарь; выбранная дата показывается сразу.
В бланке предпросмотр листа: щипок двумя пальцами меняет масштаб, двойное касание переключает «крупно / вся страница», один палец сдвигает лист. Свайп влево/вправо между «Отчёт» и «Бланк» работает и над полями ввода.

Компьютер
Тот же файл index.html работает и на компьютере: на широком экране приложение показывает компьютерный вид (верхняя панель, две колонки, окна по центру, клавиши N, T, 1-4, Esc, Ctrl+P). Как поставить его на Windows, написано в архиве otchet-windows.zip.

Анимации
Если в системе отключены анимации, приложение их не показывает (так задумано). Windows: Параметры -> Специальные возможности -> Визуальные эффекты -> Эффекты анимации. Android: Настройки -> Специальные возможности -> Удалить анимацию (или режим экономии заряда).

Обновление страницы
Потяните экран вниз в самом верху страницы (когда список прокручен до начала): появится кружок со стрелкой, отпустите, когда он станет оранжевым. Приложение сохранит данные, проверит новую версию и перезагрузится.

Печать маркировки (этикетка «Экотар - Факт производства»)
На каждом заказе есть печать маркировки. На телефоне: нажмите заказ и удерживайте, потом потяните его ВПРАВО до надписи «Печать» (как «Перенести» и «Удалить», только с другой стороны) и отпустите. Откроется окно: вверху предпросмотр этикетки, ниже все поля, любое можно изменить. Из заказа подставляются: № заказа, № техкарты, размер (Д×Ш), профиль (B, E или BE), цвет, наименование «Гофролист», дата изготовления (дата отчёта) и назначение (заказчик). Цвет: если в «Сырье» есть «БЕЛ» в любой строке - «Белый», иначе «Бурый». Пустыми остаются: часть, марка, количество, № кипы, дата отгрузки и логистика (высота паллеты, раскладка, стрейч, уголки, лента) - их вводят вручную.
КИП и копии: «1-6» в поле «№ кипы» и 6 копий дают 6 листов, на них КИП 1/6, 2/6 ... 6/6 (галочка «КИП вида 1/6» отключает «из N»: будет просто 1, 2 ... 6). При вводе диапазона число копий подставляется само, его можно поменять. Если в поле не диапазон (например 4/4), оно печатается как есть на каждом листе.
Лист печатается всегда вертикально (А4, портрет), этикетка стоит в нижней части листа, как в образце; QR - заглушка из образца. Шрифты как в образце (Arial Black и Arial): если такого шрифта на устройстве нет, берётся ближайший, слишком длинные значения сами уменьшаются, чтобы не вылезти из клетки.
